HOW TO USE — Stretch GazeBot
============================
Control your Stretch 3 robot's head by moving your own head
while wearing Xreal One Pro glasses.


WHAT YOU NEED
-------------
- Xreal One Pro glasses
- USB-C cable
- Hello Robot Stretch 3 (same network as your PC)
- Python 3 on your PC


============================================================

============================================================
FULL SETUP
============================================================

STEP 1: PLUG IN THE GLASSES
---------------------------
1. Connect Xreal One Pro to your PC with a USB-C cable.
2. Verify the link:
       ping 169.254.2.1
3. If no replies:
   - Glasses settings > developer menu > enable ethernet
   - Try a different USB-C port


STEP 2: TEST THE GLASSES (IMU VISUALIZER)
-----------------------------------------
1. On your PC:
       cd ~/lab/life_home/xreal_head_control
       python3 imu_server.py
2. Open the viewer in a browser:
       xdg-open imu_viz.html
3. You should see a 3D cube tracking your head motion.
4. Ctrl+C to stop.


STEP 3: START THE ROBOT
-----------------------
1. SSH into the Stretch:
       ssh hello-robot@172.22.243.8       # password: ask lab admin
2. Deactivate conda in EVERY terminal you open on the robot:
       conda deactivate
3. Free any stuck processes and home the robot:
       stretch_free_robot_process.py
       stretch_robot_home.py
4. Start the launch file:
       ros2 launch ~/het_ros2_ws/stretch_dual_camera.launch.py
5. Open a SECOND SSH session:
       ssh hello-robot@172.22.243.8
       conda deactivate
6. Confirm the action server name:
       ros2 action list
   Look for something like /stretch_controller/follow_joint_trajectory.
   If the name differs, edit line 33 of:
       nano ~/het_ros2_ws/stretch_relay.py
7. Start the relay:
       python3 ~/het_ros2_ws/stretch_relay.py
   Wait for: "Waiting for connection on port 9090..."


STEP 4: START HEAD CONTROL (ON YOUR PC)
---------------------------------------
1. Open a terminal:
       cd ~/lab/life_home/xreal_head_control
       python3 stretch_head_control.py
   (Or run from anywhere: python3 ~/xreal_head_control/stretch_head_control.py)
2. Keep the glasses STILL on a flat surface for ~0.5 s (calibration).
3. Put them on.
4. Press T to set the current pose as "center".
5. Move your head:
   - LEFT / RIGHT  -->  robot pans
   - UP / DOWN     -->  robot tilts


============================================================
KEYBOARD CONTROLS
============================================================
  Key            Action
  -------------  ---------------------------------
  M              Toggle LOOK / DRIVE mode
  Space (hold)   Move base (DRIVE mode only)
  T              Zero view (both modes)
  R              Recalibrate (hold glasses still)
  L              Lock / unlock tracking
  Q              Quit

============================================================
TROUBLESHOOTING
============================================================

"Connection refused" on PC
    --> Start stretch_relay.py on the robot first.

"Trajectory server not found" on robot
    --> Make sure stretch_driver.launch.py is running in another
        terminal. Run "ros2 action list" and update the action
        server name in stretch_relay.py.

Can't ping 169.254.2.1
    --> Enable ethernet in glasses developer menu;
        try a different USB-C port.

Python errors about rclpy on the robot
    --> Run "conda deactivate" before any python3 commands.

Head moves wrong direction
    --> In stretch_head_control.py, flip the sign on line 108 or 109.

Too sensitive / not sensitive enough
    --> Edit stretch_head_control.py:
        HEAD_PAN_SCALE  = 0.025   # bigger = more sensitive left/right
        HEAD_TILT_SCALE = 0.015   # bigger = more sensitive up/down


============================================================
FILES
============================================================
PC-side:
    stretch_head_control.py    Reads glasses, sends commands to robot
    imu_server.py              Streams head data to browser (test tool)
    imu_viz.html               3D cube viewer (test tool)
    src/imu_reader_fixed.py    Reads raw IMU over TCP
    src/head_tracker.py        Converts raw IMU -> pitch/yaw/roll
    src/imu_data.py            IMU data format
    src/imu_reader.py          Original reader (does not work w/ our glasses)
    start.sh                   Launcher (checks glasses before starting)

Robot-side:
    ~/het_ros2_ws/stretch_relay.py                  Receives PC commands, moves head
    ~/het_ros2_ws/stretch_dual_camera.launch.py     Dual camera launch
